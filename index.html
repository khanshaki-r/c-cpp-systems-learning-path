    C, C++ Systems Engineering Learning Path¶

    A 12-week curriculum that takes a working C programmer to production-depth knowledge of C, modern C++17, concurrency, debugging, Linux, databases and distributed systems, built around one real project: a multithreaded TCP key-value server.

    Every module follows the same shape: plain words first, then the real mechanism, complete code, what happens under the hood, how it fails in production, exercises, and interview questions.

    How to use this site¶

    1. Follow the week-by-week table in Start here. Study three or four courses in parallel, one module per sitting.
    2. Type the code yourself. Every program is linked to GitHub and builds with -Wall -Wextra -Werror on GCC 13.
    3. Press Mark as done at the top of a module when you can say its recap out loud without looking. Your progress is saved in this browser only.
    4. Use the search box (press /) to find any topic across all courses.
